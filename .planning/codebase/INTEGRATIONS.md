# External Integrations

## Firebase
- **Authentication:** Manages user sign-up, login, and sessions.
- **Firestore:** Stores structured data, user profiles, and application state dynamically.

## Google Generative AI (Gemini)
- Integrated via `google_generative_ai` SDK to provide continuous AI chat assistance directly in the app.

## Device APIs (Hardware Integrations)
- **Geolocator:** Fetching physical device coordinates (GPS) for real-time location mapping and sharing.
- **Image Picker:** Native integration for picking medical records or profile avatars.
- **URL Launcher:** Deep-linking utilities (e.g. launching map URLs, dialing phone numbers).
